# Definition of Done

A task is complete only when all applicable items pass.

## Product and content

- The change advances a documented product goal.
- Copy follows the voice guide.
- Every factual claim is supported by `facts.md`, a project source, or explicit user confirmation.
- No placeholder, fake metric, or NDA-sensitive content remains.

## Design

- The result follows Engineering Editorial art direction.
- Anti-AI rules pass.
- Desktop, tablet, and mobile compositions are intentional.
- Empty space, hierarchy, and project-specific composition are reviewed.
- Motion has a purpose and reduced-motion behavior.

## Engineering

- Semantic HTML and TypeScript rules pass.
- No unnecessary client JavaScript or dependency was introduced.
- Production static build succeeds.
- GitHub Pages base paths work.
- Tests cover meaningful logic and critical navigation.

## Accessibility

- Keyboard navigation and visible focus pass.
- Heading order and landmarks pass.
- Contrast and zoom pass.
- Images and diagrams have appropriate alternatives.
- Automated accessibility checks show no serious or critical violations.

## Quality evidence

- Relevant commands were run and results recorded.
- Visual changes were inspected at representative viewports.
- No console errors, broken links, or missing assets.
- Remaining risks or untested areas are stated explicitly.
