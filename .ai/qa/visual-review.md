# Visual Review Rubric

Score each category `PASS`, `NEEDS WORK`, or `FAIL`. Cite visible evidence.

## Hierarchy

- Is the first reading path obvious?
- Are metadata and primary content visibly distinct?
- Is emphasis achieved without excessive color or scale?

## Composition

- Does the layout use controlled asymmetry?
- Are alignments and rhythms intentional?
- Does each project composition respond to its content?

## Typography

- Are font roles consistent?
- Is body measure readable?
- Are line breaks, tracking, and fluid sizes controlled?

## Originality

- Run substitution, content-dependency, screenshot, and purpose tests from `anti-ai.md`.
- Identify any generic AI/SaaS pattern explicitly.

## Responsive behavior

- Review at 320, 375, 768, 1024, and 1440 CSS pixels where practical.
- Check overflow, clipped text, unintended stacking, touch targets, and diagram legibility.

## States

- Keyboard focus.
- Hover and active states.
- Current navigation item.
- Empty/missing optional content.
- Reduced motion.

## Review output

Return:

1. Verdict.
2. Blocking findings.
3. Non-blocking findings.
4. Strong decisions worth preserving.
5. Exact recommended changes, ordered by impact.

Never return only “looks modern and polished.”
