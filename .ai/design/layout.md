# Layout

## Grid

- Desktop: 12-column editorial grid with wide outer margins and explicit gutters.
- Tablet: 8 columns.
- Mobile: 4 columns with 20–24px page padding.
- Maintain a consistent content container, but allow selected visual elements to break the grid deliberately.

## Composition

- Use controlled asymmetry, not random offsetting.
- Build each selected-work section around its actual content rather than repeating one card template.
- Use whitespace as an active structural element.
- Align metadata rigorously even when main compositions vary.
- Favor long horizontal rules, numbered sections, and changing text/image proportions.

## Homepage hero

The hero should combine:

- large identity typography;
- concise professional positioning;
- Tokyo / worldwide availability metadata;
- a meaningful system-flow diagram or structured capability annotation.

Do not use the standard badge → centered headline → paragraph → two rounded buttons stack.

## Case studies

- Use a readable document column for narrative sections.
- Allow diagrams and screenshots to expand beyond the text column.
- Keep a compact facts rail or opening metadata block.
- Provide visible section navigation for long studies.

## Mobile

- Do not merely stack desktop columns in source order without editorial review.
- Recompose hero and diagrams for narrow screens.
- Keep tap targets at least 44×44 CSS pixels where applicable.
- Avoid horizontal scrolling except in explicitly labelled technical specimens with an accessible alternative.
