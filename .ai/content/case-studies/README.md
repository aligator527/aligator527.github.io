# Case-Study Working Notes

Store one private-safe working file per intended case study in this directory.

Recommended names:

- `next-generation-wms.md`
- `ai-chat-platform.md`
- `packaging-saas.md`
- `multilingual-web-platforms.md`

Do not commit confidential raw notes. If a study requires private source material, keep it outside the public repository and commit only the sanitized output.

Use `[FACT REQUIRED]`, `[NDA REVIEW]`, and `[METRIC SOURCE]` markers during drafting.
