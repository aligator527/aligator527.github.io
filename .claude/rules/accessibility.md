# Accessibility Rules

- Target WCAG 2.2 AA.
- Use native semantics before ARIA.
- Maintain heading hierarchy, landmarks, skip navigation, and visible focus.
- Make pointer interactions available by keyboard and on touch devices.
- Provide accessible alternatives for architecture diagrams.
- Do not communicate information by color or motion alone.
- Respect reduced motion.
- Avoid fixed-height text containers.
- Test keyboard order, 200% zoom, 320px width, contrast, and automated axe checks for relevant changes.
